# lms-ai-textbook-tutor
Agentic Textbook Ingestion &amp; AI Tutor RAG service for LMS. Features PDF chunking, diagram extraction via PyMuPDF/Cloudinary, Matryoshka vector search in Qdrant, Cohere reranking, and LangGraph-driven Gemini SSE streaming with authentic syllabus citations and LaTeX math formatting.
